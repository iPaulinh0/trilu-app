Pill-shaped action button — use `primary` (violet) for navigation-level actions and `accent` (coral) for the one goal-driving CTA per screen.

```jsx
<Button variant="accent" size="lg" block>COMEÇAR TREINO</Button>
```

Variants: primary · accent · success · secondary · outline · ghost. Sizes sm/md/lg (36/44/56px). `block` for the single main action; never put two `accent` buttons on one screen.
